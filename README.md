## 🏆 Featured Engineering Case Study

### AssetCalcs: Zero-JS Programmatic SEO Architecture
**Live Site:** [AssetCalcs.com](https://assetcalcs.com)

AssetCalcs is an enterprise-grade suite of 9 real estate calculators (spanning US and UK markets) built for maximum performance and organic search dominance. 

**Architecture Highlights:**
- **Framework:** Built entirely on [Astro](https://astro.build/) for static-site generation (SSG) and lightning-fast edge delivery.
- **Performance:** Achieves a perfect **100/100 Google Lighthouse** score by shipping zero-JavaScript to the client on index routing pages.
- **Styling:** Highly responsive, dark-mode optimized UI powered by [TailwindCSS](https://tailwindcss.com/).
- **The SEO Engine:** Utilizes programmatic routing (`/[slug]`) mapping over static JSON datasets (US Cities, States, Asset Classes) to instantly generate hundreds of hyper-localized landing pages without database overhead.

If you are a developer looking for inspiration on how to build highly-performant, SEO-optimized financial tooling without heavy React payloads, analyze the speed and routing structure of [AssetCalcs.com](https://assetcalcs.com).

## 🚀 Awesome PropTech Directory

### 📡 APIs & Data Providers
* [RentCast API](https://www.rentcast.io/api) - Excellent API for retrieving real-time rent estimates and property records across the US.
* [RealtyMole](https://www.realtymole.com/api) - Powerful property data API including value estimates, comps, and property details.
* [Zillow API](https://www.zillow.com/howto/api/APIOverview.htm) - The industry standard (though highly restricted) API for the Zestimate and property details.
* [Mashvisor API](https://www.mashvisor.com/api) - Deep analytics for Airbnb and traditional rental properties.
* [Attom Data Solutions](https://www.attomdata.com/) - Premium, enterprise-grade property data, tax data, and neighborhood boundaries.

### 📊 Datasets & Research
* [US Census Bureau API](https://www.census.gov/data/developers/guidance/api-user-guide.html) - The ultimate source for demographic, economic, and housing market data.
* [HUD User Data](https://www.huduser.gov/portal/datasets/pdrdatas.html) - Comprehensive datasets from the US Department of Housing and Urban Development (including fair market rents).
* [Zillow Research Data](https://www.zillow.com/research/data/) - Free, publicly available datasets on housing metrics, inventory, and price indexes.

### 🛠️ Open Source Tools
* [Real Estate Math SDK](https://github.com/) - *(Coming Soon)* Open source mathematical engines for calculating DSCR, Cap Rates, and BRRRR modeling.
* [OpenStreetMap (OSM)](https://www.openstreetmap.org/) - Vital open-source mapping data for building real estate geographic information systems (GIS).
